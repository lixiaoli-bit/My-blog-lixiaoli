# 块内输入、光标与滚动稳定性修复

日期：2026-10-12。基于《计算机组成原理-强化讲义》的只读隔离正文排查；本次开发和测试没有改写真实文章、数据库或客户端暂存。

## 根因与对照实验

1. 外层装饰重建时，引用块的 `updateDOM` 无条件接受另一块的描述。CodeMirror 复用旧 DOM 的过程中，活动子编辑器被装入相邻引用块的正文。原位置连续三次复现：Enter 前光标为 151，之后重置为 0；滚动位置从 1773 跳到 2110。折叠面板、选项卡及分栏采用了类似同步方式。
2. 块更新丢失实测高度估算，导致外层虚拟高度模型及滚动锚点漂移。在已修正块身份与光标的版本中，仅临时禁用实测高度估算，仍复现 1773 → 2110，同时光标正常为 151 → 152；启用实测高度后为 1773 → 1773。这是额外 337 像素跳动的独立对照证据。
3. 嵌套选区未完整投影到外层，撤销采用过期的外层光标位置，可能使活动编辑器离开视口。面板扫描还会把正文末尾新输入的空行当作容器留白，回写时删掉新行。
4. 文章以引用块开头、外层选区仍在 0 时，虚拟化重新挂载引用块会重新执行标题聚焦，原本已滚到 1800 的视口被拉回 0。现在仅在用户输入新建引用块时允许一次焦点转移，普通虚拟挂载不会抢焦点。

上述行为发生在编辑器的局部装饰、内容同步和几何测量过程中；没有每次重建整个 React 页面。此前修复的全局折叠高度失效问题仍有回归覆盖，本次补上实际输入路径。

## 最终实现

- 引用、折叠面板、选项卡和分栏持有编辑会话内的稳定身份。通过事务映射源码范围，同标题、同内容的相邻块仍具有不同身份；不同身份禁止复用控制器。
- 稳定身份保留实测高度，并提供给 CodeMirror 的 `estimatedHeight`。尺寸变动仍只更新对应块；没有循环强制还原旧 `scrollTop`，正常的底部光标跟随与滚轮继续工作。
- 块内修改向外层提交最小变化，保留未编辑的引用前缀、分栏留白和折叠缩进；两空格与 Tab 折叠缩进均覆盖。分栏只有遇到嵌套语法需要提升围栏时才重写容器。
- 子选区沿拥有者同步到外层。反向内容同步延后至当前事务完成，用最小变化映射光标，内容一致则跳过。
- 三层嵌套的撤销重做由根编辑器保存历史，活动子编辑器提供实际光标几何；只在历史目标属于当前子编辑器时转交滚动请求，其他历史目标仍使用普通定位。空引用行插入缩进时补上必要的引用分隔空格，避免首个缩进被吃掉并破坏内层折叠语法。
- 可视指令记录当前会话的正文范围，把作者输入的空行和语法容器留白分开；源码模式仍正常重新解析，没有修改保存 API、数据库结构或持久化 Markdown 语法。
- 空引用、空折叠、空选项卡和无留白的空分栏均可直接输入、换行；必要时只补上防止正文与下一条语法标记粘连的容器留白。

## 验证命令

```powershell
pnpm exec vitest run --maxWorkers=4
pnpm check
pnpm exec node scripts/check-editor-kernel.mjs
pnpm exec node scripts/check-nested-input.mjs
pnpm run build:portable --target portable-input-20261012
pnpm exec node scripts/verify-editor-portable.mjs portable-input-20261012
pnpm exec node scripts/verify-article-interactions.mjs portable-input-20261012 --nested-input
```

`NESTED_INPUT_FIXTURE` 可指定只读 Markdown 样本；`EDITOR_SCROLL_FIXTURE` 用于既有长文折叠回归。Electron 脚本用 `ARTICLE_FIXTURE_DB` 配合 `ARTICLE_FIXTURE_ID` 或 `ARTICLE_FIXTURE_TITLE` 只读抽取文章，再写入独立临时数据库，绝不在真实库内测试输入。

输入回归覆盖同标题且不同高度的引用、折叠、选项卡、分栏、嵌套引用、大块底部光标跟随、Tab 缩进和私有文章样本。每组检查真实 Enter、连续中文输入、删除、粘贴、撤销重做、CDP 中文组合输入及末尾换行；核对活动子编辑器身份、光标、完整源码与滚动位置。

补充三层“分栏→折叠→引用”和“引用→折叠→引用”、虚拟挂载不抢焦点、保留原有较长分栏围栏，以及四种空容器输入与源码模式往返，共 16 组输入回归。

已完成 102 个测试文件、1186 项单元测试；类型检查为 0 错误、0 警告（51 条既有提示）。既有编辑内核浏览器回归 45 项和本次输入回归 16 组均通过，隔离文章复现点 Enter 后滚动保持 1773，光标从 151 前进到 152。

最终独立便携包约 810 MB，真实 Electron 的编辑器 6 项及文章工作区 23 项验证全部通过。包内隔离文章的 Enter 检查逐字符核对完整源码，确认自动保存、撤销重做、预览及重新打开保留预期输入；实际鼠标滚轮和反复折叠也没有跳转。组合输入通过 Chromium CDP 模拟，仍需用户在自己的输入法环境中体验确认。

测试输出位于忽略的 `outputs/nested-input`、`outputs/editor-kernel` 和 `outputs/article-workspace`；私有正文、数据库及便携构建产物不提交 Git。

## 使用新版

项目版本沿用 1.1.3，独立便携目录为 `release/portable-input-20261012`。先保存并完全退出旧客户端（包括托盘），再打开该目录中的 `白衣卿相.exe`；保留整个目录及 `resources`。旧便携目录保留，不替换正在运行的客户端。
