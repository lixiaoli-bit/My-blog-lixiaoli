## 1. 修复结果与实现取舍

| 问题 | 结果 | 实现与保留边界 |
| --- | --- | --- |
| 相邻 Callout、分栏、折叠块间空行点不中 | 左、中、右点击后均能在空行输入 | 块外层 margin 为 0，留白放入可测量的 padding，卡片外观仍在内层；不插入 Markdown 空行或给鼠标坐标加补偿 |
| 收起 Callout 后短文固定高度编辑区仍用旧高度 | 动态折叠后的模型位置、鼠标落点一致 | ResizeObserver 请求测量；实际高度变化发送布局状态效果，使块装饰身份更新，通过 updateDOM 复用子编辑器。效果不修改文档、不新增撤销输入 |
| 表格中文组合输入停顿后重复文本 | 最终为 x中文；一次撤销恢复输入前源码 | composition 期间禁止防抖、显式 flush 和结构操作提交；确认 Enter 不新增行；结束后读取最终 DOM。取消组合输入不为分隔符规范化增加历史 |
| 嵌套强调、转义星号、多反引号代码误显示 | 标记与正文范围正确 | 两种预览共用已安装的 CodeMirror GFM 解析器。按不可变 Text 缓存完整语法范围，光标移动复用装饰，不依赖尚未解析完整的视口语法树 |

使用统一包装容器而非仅删除留白，可以保留卡片边框、背景、圆角和内部控件。新增布局状态效果是浏览器回归暴露的必要补充：固定高度内容盒可能不随折叠变化，仅调用 requestMeasure 没有让 CodeMirror 重测块高度。折叠后旧实现实际落点 18、预期 19；补充后两者均为 19。

表格继续使用现有 contenteditable 单元格与行列操作，没有整体替换为 Obsidian 的单元格 CodeMirror。普通 Tab、Enter 和增删行继续工作；销毁表格会清理防抖与菜单监听，旧表格的延迟焦点恢复只作用于仍连接的 DOM。

标准语法解析只接管强调、删除线、转义及行内代码。项目链接/图片 Widget、数学、下划线、剧透、提示、高亮、脚注及容器扫描仍沿用现有管线，阅读预览继续使用 renderMdx。本轮没有重写保存业务或引入 Obsidian 的私有实现代码。

## 3. 验证范围

新增标准语法测试先在旧实现上运行，8 项全部失败，分别复现两种预览中的嵌套强调、转义、代码与下划线问题；修改后通过。鼠标与表格旧行为的原始失败证据保留在阶段 A 实验记录。新增动态折叠回归又复现了高度 18/19 偏差，促使补充布局失效机制后通过。

相关 Vitest：8 个文件、65 项测试通过。覆盖标准语法、装饰缓存、表格、分栏、可视指令、交互 HTML、待保存正文与保存队列。

独立浏览器：37 项通过，包括：

- 7 类块/引用的左、中、右空行真实点击和后续输入，21 项。
- 3 组标准语法的实际显示文本。
- 表格停顿 450ms 的合成中文 IME；组合期间 Enter 与显式 flush；最终文本、一次撤销；组合取消；普通 Tab/Enter。
- 视觉/源码往返保持 EditorView、文档、选区与撤销。
- 动态折叠高度、分栏添加/编辑/合并及再次空行定位、Tabs/折叠子编辑；下划线、剧透、提示、高亮、数学、脚注样例与任务勾选；交互 HTML 运行前 iframe 为 0。
- 首页文章、文档原位编辑、日历日记、速记浮窗四个实际 React 组件各一个 Callout 空行点击并输入。
- 浏览器运行异常检查。

夹具构建使用真实组件、项目实际 global.css、已安装的 Tailwind 编译器及字体资源；字体 URL 已按源位置重写。Tailwind 类名清单限制在产品源码与夹具。Vite 开发服务器依赖处理在本机持续阻塞，因此采用独立生产构建及回环预览，不依赖开发服务器或业务 build 脚本。

宿主 API 完全用合成内容 mock，验证的是实际组件集成和输入落点；这不等于真实后端持久化、网络故障与冲突已验收。测试只绑定 127.0.0.1，结束关闭浏览器与预览服务。
