# v1.1.4 · Windows 桌面版

当前正式发行仅支持 Windows x64。

- 修复编辑模式点击三级、四级目录时高亮落在前一个标题的问题，包含相邻同名标题与末尾标题。
- 增加文章封面手动上传；编辑界面右键封面可删除，保留正文与原始媒体文件。
- “立即同步”显示运行状态、耗时及完成或失败反馈，避免旧状态请求覆盖新结果。
- 恢复全局字体设置；未指定文章字体时跟随全局字体，均未设置时使用默认字体。
- 首次安装自动创建本地 SQLite 和配置，支持本地使用及从设置打开云端部署教程。
- 随桌面版提供包豪斯风格部署教程，说明 Vercel、PostgreSQL、可选备库、R2 和 GitHub 图床。
- 清理一次性诊断脚本、无引用字体副本及根目录视频产物；保留 Android、宣传站和宣传视频源码。发布构建采用独立目录。

## 下载与升级

`My-Blog-1.1.4-Windows-x64-Setup.exe` 为安装包；`My-Blog-1.1.4-Windows-x64-Portable.zip` 为便携包。便携包必须完整解压并保留整个目录。

升级前保存文章并通过托盘退出旧版。本地配置、数据库与缓存保留在 `%APPDATA%\\byqx-blog-desktop\\`。本版尚未签名，Windows 可能显示 SmartScreen 提示。

- 104 个测试文件、1195 个测试通过；Astro 检查无错误、无警告。

- 安装包与便携 ZIP 的归档完整性检查通过；未在现有用户环境覆盖安装。
- 部署教程通过桌面与移动宽度、链接、剪贴板反馈和清单持久化检查。

云端数据库、R2 与 GitHub 图床的真实上传和跨设备同步仍取决于使用者的配置，本次未使用生产库验证这些外部服务。
